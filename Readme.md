Проект реализует решение матричной игры с нулевой суммой:
- методом Брауна–Робинсона (итерационный алгоритм)
- методом линейного программирования (SciPy)

Также выполняется визуализация результатов и анализ сходимости.

---

## 📌 Требования

- Python 3.9+
- pip

---

## 📦 Установка

### 1. Клонирование проекта

```bash
git clone <repository_url>
cd <project_folder>
```

## 📌 Создание виртуального окружения
```
python -m venv venv
venv\Scripts\activate
```

## 📌 Установка зависимостей

```
pip install -r requirements.txt
```

## 📌 Запуск проекта

```
python main.py
```
